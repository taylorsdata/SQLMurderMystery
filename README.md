# 🕵🏽‍♀️ SQL Murder Mystery: COOP Case File

Welcome to my official detective dossier from the **COOP Careers SQL Murder Mystery** challenge. Join me as I dig through city records, witness statements, and crime logs to uncover whodunnit—with nothing but SQL and a sharp eye for scandal.

## 🧩 Challenge Overview
This project is based on the [SQL Murder Mystery](https://colab.research.google.com/github/freestackinitiative/coop_sql_notebooks/blob/v2/notebooks/COOP_SQL_Murder_Mystery.ipynb), where I solved a fictional crime using only SQL queries and data sleuthing.

## 💻 Tools Used
- SQL (Google BigQuery)
- Google Colab Notebook
- GitHub for version control + presentation

## 📂 Project Breakdown
- `coop_sql_murder_mystery.ipynb`: The full notebook with queries and outputs.
- `queries/`: Cleaned versions of my queries used to solve each stage.
- `notes/reflections.md`: Key learnings + fun takeaways from my detective journey.
